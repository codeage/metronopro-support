MetronoPro Support

Need help with the metronome or have an idea for improving it? Contact the developer through the public GitHub issue tracker.

Contact support on GitHub

For a bug report, include your device model, iOS version, app version and steps to reproduce the problem. GitHub issues are public. Keep payment and account details out of the report.

Purchases and subscriptions

If you have already purchased access, use Restore Purchases in the app while signed in to the Apple Account you used to buy it. To manage or cancel a subscription, open Settings, tap your name, then tap Subscriptions.

节拍专家支持

遇到问题或有改进建议，可以通过 GitHub Issues 联系开发者。

在 GitHub 提交反馈

反馈故障时，请附上设备型号、iOS 版本、App 版本及复现步骤。反馈会公开显示，请勿填写账号或付款信息。

购买与订阅

如果已经购买，请使用当时购买的 Apple 账户，并在 App 内选择「恢复购买」。如需管理或取消订阅，请打开 iPhone「设置」，轻点你的姓名，再选择「订阅」。

節拍專家支援

遇到問題或有改進建議，可以透過 GitHub Issues 聯絡開發者。

在 GitHub 提交意見

回報問題時，請提供裝置型號、iOS 版本、App 版本與重現步驟。意見會公開顯示，請勿填寫帳號或付款資訊。

購買與訂閱

如果已經購買，請使用當時購買的 Apple 帳號，並在 App 內選擇「回復購買」。若要管理或取消訂閱，請開啟 iPhone「設定」，點一下你的姓名，再選擇「訂閱」。
